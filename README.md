# Sysadmin & Security Triage

An advanced collection of PowerShell automation scripts built for Windows systems administration, network security, and proactive endpoint auditing.

---

## Repository Scope & Capabilities

This repository serves as a centralized toolkit for deep-dive Windows administration and security operations. Designed to streamline administrative workflows and threat hunting from the command line, the scripts cover:

* **Network Security & Testing:** Mapping active listeners, auditing connections, and analyzing network behavior.
* **Process Management & Lineage:** Tracking processes, dissecting process execution chains, and revealing parent-child relationships to spot anomalies or unauthorized execution.
* **Local User & Account Auditing:** Automating user account enumeration, tracking privileges, and handling account lifecycle management (creation and deletion).
* **System Triage & Diagnostics:** Rapidly gathering host telemetry, debugging configurations, and running live system health checks.
* **Service Auditing & Debugging:** Inspecting Windows services to identify misconfigurations or unexpected background states.
* **System State Automation:** Resetting, enabling, or modifying critical Windows settings and features programmatically.

---

## Usage

All scripts are written in native PowerShell and optimized for performance using efficient CIM/WMI caching. 
Run PowerShell with administrative privileges to execute the scripts for full system access
