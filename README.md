# Sysadmin & Security Triage

A collection of PowerShell and Python scripts focused on Windows administration, troubleshooting, networking, and security.

This repository includes both completed and practice scripts as I continue building my skills.

## Areas Covered

* Network and connection auditing
* Process and service analysis
* Local user account management
* System diagnostics and troubleshooting
* Windows security auditing
* PowerShell and Python automation

## Usage

Some scripts may require administrator privileges.

Review and test scripts in a lab or virtual machine before using them on a production system.
